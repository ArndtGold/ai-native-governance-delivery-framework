## NAME

`sd-definition` - draft and clarify a bound unapproved solution design

## SYNOPSIS

`/sd-definition` [`--help`|`-h`]

## DESCRIPTION

Derives technical ownership, solution decisions and acceptance traceability from the approved
PRD and applicable analyses after bound dispatch. Keeps material unresolved decisions visible.
Draft revision uses canonical recording and a fresh presentation before human approval.
