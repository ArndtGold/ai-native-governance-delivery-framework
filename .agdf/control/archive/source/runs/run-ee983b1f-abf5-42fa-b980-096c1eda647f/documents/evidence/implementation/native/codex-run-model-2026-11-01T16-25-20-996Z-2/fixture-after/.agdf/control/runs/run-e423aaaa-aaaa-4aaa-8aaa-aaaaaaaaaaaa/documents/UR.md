## 1. Problem

A personal filter must be recreated repeatedly.

## 2. Goal

Save and restore an individually named personal filter.

## Affected Users

The same user who creates, saves and restores the filter.

## 3. Scope

One filter belonging to the same user, saved under a chosen name and restored by that user. No sharing or permission changes.

## 4. Non-Goals

No sharing with other users.

## 5. Acceptance Signals

The user can save one personal filter with a name and restore its saved criteria without recreating them. Sharing and permissions remain unchanged.

## 6. Existing Source Of Truth

The user's request is the requirements source. No existing product code or document owner has been identified in this fresh disposable repository.

## 7. Risks And Unknowns

Storage and interaction details remain for later PRD and design work; they do not change this bounded need.
