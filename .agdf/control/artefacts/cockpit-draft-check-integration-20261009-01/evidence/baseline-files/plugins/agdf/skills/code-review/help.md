## NAME

`code-review` - code review

## SYNOPSIS

`/code-review` [`--help`|`-h`]

## DESCRIPTION

Produces the mandatory Code Review Report for changed code and focuses on correctness, regression, security, and other materially relevant findings before QA.

## EXAMPLES

Trigger the skill:

```text
> /code-review
```
