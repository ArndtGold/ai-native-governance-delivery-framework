## 1. Problem

A personal filter must be created repeatedly.

## 2. Goal

Save and restore a user's own named filter.

## Affected Users

The same user who creates and reuses the personal filter.

## 3. Scope

One filter belonging to the same user, including saving it with a name and restoring it. No sharing or permission changes.

## 4. Non-Goals

Sharing with other users is excluded.

## 5. Acceptance Signals

The user can save one named personal filter and restore that saved filter without recreating it. The filter remains personal and permissions remain unchanged.

## 6. Existing Source Of Truth

The user's request is the source of the need. No existing product code or repository owner has been identified in this fresh disposable repository.

## 7. Risks And Unknowns

Storage, naming details and existing filter integration are deferred to later analysis; they do not expand this single-user scope.

## 8. Next Step

Prepare the UR for review in an unapproved Run. No approval or implementation is requested in this contract test.
