## 1. Problem

A personal filter has to be created repeatedly.

## 2. Goal

Save and restore an own named filter.

## Affected Users

The same user who creates and restores their personal filter.

## 3. Scope

One named filter belonging to the same user. Save and restore it without sharing or changing permissions.

## 4. Non-Goals

No sharing with other users. No permission changes.

## 5. Acceptance Signals

The user can save a personal filter under a name and later restore that filter without recreating it. It remains personal to the same user.

## 6. Existing Source Of Truth

The user's request is the requirements source. Existing product code and ownership have not been identified in this fresh disposable repository.

## 7. Risks And Unknowns

Storage and UI details remain for later analysis; they do not change the requested personal-only scope.

## 8. Next Step

Prepare the UR presentation for review. Do not request or record approval, implement, or migrate anything in this contract check.
