## 3. Test Plan

Reuse first: the existing companion suites, gate-check and status-card tests, MCP server suites and CLI MCP suites cover unchanged behavior and are run unchanged. New collection is planned only for claims they do not cover: the run view and its command, diagnosis, the companion process boundary, events, journal, review facts and catalog completeness. One scenario run may support several criteria; nothing is repeated without a changed condition.

Placement: targeted run checks of increment 1 (SCN-001 to SCN-004, SCN-006, SCN-016, SCN-017, SCN-020, SCN-022 and the golden part of SCN-018) pass before T-007 starts. All targeted checks pass on the final revision before Code Review. PR CI (`npm run verify:ci`) is required before merge. No nightly result is relied on.

Defect proof: the T-001 divergence cases were run on the unchanged code and failed for the intended reason (evidence `T-001-companion-parity-baseline.md`); they must pass after T-006 without changing their assertions.

Process boundary: adapter tests use a fake `$.process.run`; real node processes run only in `run-view-command-test.js`, the host-neutral harness and the native check, so suite time stays bounded.

Sufficiency: verification is complete when SCN-001 to SCN-024 pass on the final revision, PR CI is green and SCN-005 has its screenshot and measured refresh time. Re-checks need a trigger: changed code after the check, a failed or invalidated result, or a new contradiction.

Known limits: concurrent journal writers are covered by a bounded interleaving test, not a multi-process stress run (SD gap). `$.process` availability is proven in the Claude desktop app only (SD gap). The desktop app draws plugin toasts only in its main window, never in a pop-out session window (T-013 observation). If `recovery_required` or a returned `effect_unknown` cannot be produced through the real tool path with the existing fault-injection seams of the MCP test harness, SCN-012 covers them with result objects validated against the published result schema, and this is recorded as an evidence limit for QA.
