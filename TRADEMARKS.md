# Trademark Guidelines

AGDF(TM) and AI Governance & Delivery Framework(TM) are marks of Arndt Gold.

These guidelines are intended to keep the project name trustworthy while the
software remains available under the Apache License, Version 2.0.

## Marks

The project marks include:

- AGDF
- AI Governance & Delivery Framework
- AGDF logos, wordmarks and distinctive project branding

## Allowed Use

You may use the AGDF marks to:

- refer to the original AGDF project
- describe compatibility with AGDF
- identify unmodified copies of the AGDF software, documentation or package
- state that your work is based on, derived from or integrates with AGDF

Use clear attribution where practical:

```text
AGDF is a mark of Arndt Gold.
```

## Not Allowed Without Permission

Do not use the AGDF marks in a way that could confuse people about origin,
ownership, endorsement or official project status.

In particular, do not:

- present a modified fork as the official AGDF project
- use AGDF marks as the primary name of another product, service, package,
  repository, domain, social account, training offer or consulting offer
- imply endorsement, certification or partnership by Arndt Gold
- use AGDF logos or branding for unrelated products or services
- remove or obscure trademark notices from redistributed project material

## Forks And Modified Versions

Modified versions should use a clearly distinct name.

Acceptable wording:

```text
Based on AGDF
Compatible with AGDF
AGDF-derived workflow for internal use
```

Avoid names that suggest official status, such as:

```text
AGDF Pro
AGDF Enterprise
Official AGDF Cloud
AGDF Certified
```

unless written permission has been granted.

## License Separation

The Apache License, Version 2.0 applies to the software and documentation unless
otherwise stated. It does not grant a trademark license for AGDF names, marks or
logos.
