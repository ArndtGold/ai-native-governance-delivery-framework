# Prompts der verständlichen UI Mockups

Diese vierte Serie ist in [AGDF Hub und Run Cockpit](../07-ui-konzept.md) eingebunden.
Sie überarbeitet alle fünf aktuellen Ansichten der dritten Serie mit verständlichen Aufgaben,
Entscheidungsfragen und Rückmeldungen. Die früheren Serien bleiben historische Entwürfe.
Erstellt am 12. Oktober 2026 mit dem integrierten Imagegen-Werkzeug, Use Case `text-localization`
für `ui-mockup`. Layout, Cockpit-Stil und Codex-Grenzen bleiben erhalten. Technische Kürzel
und exakte Antwortformeln stehen im Zielkonzept hinter geschlossenen Details. Die vorhandene
Klickqualifizierung wird durch die neuen Beschriftungen nicht geändert.
