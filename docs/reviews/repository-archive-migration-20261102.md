`run-folders-v1` scaffold and a read-only `cockpit-archive/1` catalogue.
Historical approvals remain historical records and grant no current authority.

## Git and local recovery boundaries

`.gitattributes` disables text conversion for archive originals so checkout on
another platform cannot invalidate their recorded byte digests. Archive files
are staged explicitly, including files beneath a historical `.gitignore`.
Local `.agdf/backups/` and unpublished `.agdf/.archive-stage-*/` directories are
ignored and excluded from this PR.

The Git-only export exposed a portability defect: empty `runs/` and `planned/`
stores vanished and the Cockpit returned `work_inventory_unavailable`.
Canonical initialization now seeds one empty `.gitkeep` per store. Its existing
plan validator permits only these exact zero-content store files; Run/control
creation stays forbidden in setup. The planned inventory ignores only an empty
regular `.gitkeep`; nonempty files, directories and symlinks do not qualify.
Run-effect assertions omit only this known inert marker or require its exact
presence; they still reject unexpected files and extra Runs. This small runtime
fix is necessary for a usable committed archive, and has focused regressions.

Original backups are retained under `.agdf/backups/control-<source-digest>/`.
Their receipts and the saved earlier published archive are local recovery data,
not repository content. The earlier empty nested directory and aborted stage
were removed only after the completed import was independently verified.
