## NAME

`agdf-brownfield-analysis` - brownfield analysis

## SYNOPSIS

`/agdf-brownfield-analysis` [`--help`|`-h`]

## DESCRIPTION

Ensures implementation in an existing system is Brownfield-oriented rather than Greenfield-style. Analyzes existing artefacts, current coverage, reuse strategy, risks, and the minimal clean implementation path.

## EXAMPLES

Trigger the skill:

```text
> /agdf-brownfield-analysis
```
