## NAME

`agdf-clean-implementation-review` - clean implementation review

## SYNOPSIS

`/agdf-clean-implementation-review` [`--help`|`-h`]

## DESCRIPTION

Evaluates solution integrity: whether the implementation is a clean primary solution or has become unnecessarily complex through fallbacks, workarounds, guards, defaults, shims, or parallel structures.

## EXAMPLES

Trigger the skill:

```text
> /agdf-clean-implementation-review
```
