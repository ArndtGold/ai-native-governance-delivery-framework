## NAME

`agdf-gate-check` - gate check

## SYNOPSIS

`/agdf-gate-check` [`--help`|`-h`]

## DESCRIPTION

Determines the earliest blocking user approval gate and derives which artefacts are allowed or forbidden, whether an exact approval is missing, and which next step is permissible.

## EXAMPLES

Trigger the skill:

```text
> /agdf-gate-check
```
