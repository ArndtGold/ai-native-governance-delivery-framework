## NAME

`agdf-release-or` - release OR

## SYNOPSIS

`/agdf-release-or` [`--help`|`-h`]

## DESCRIPTION

Creates the mandatory Orchestration Report (OR) for a run. Summarizes gate status, delivered artefacts, TP coverage, Brownfield fit, solution integrity, open points, and the next permissible step.

## EXAMPLES

Trigger the skill:

```text
> /agdf-release-or
```
