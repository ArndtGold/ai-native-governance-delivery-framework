## NAME

`delivery-path-search` - delivery path search

## SYNOPSIS

`/delivery-path-search` [`--help`|`-h`]

## DESCRIPTION

Compares materially different high-impact delivery paths using scope, risk, evidence, tests, cost, and gate readiness. The result is advisory and read-only; canonical AGDF `gate-check` remains the authority for what may happen next.

## EXAMPLES

Trigger the skill:

```text
> /delivery-path-search
```
